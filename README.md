# Utilities

This repository is a personal C++ practice project focused on revisiting the language through the C++ Standard Library.

For most of this year, I have been working primarily in C. I created this project to refresh my C++ knowledge and become more comfortable again with modern C++ syntax, features, and standard library utilities.

## Purpose

The goal of this project is to work through different parts of the C++ Standard Library and build small examples that help reinforce how they are used in practice.

Topics may include:

* Containers
* Iterators
* Algorithms
* Strings
* Streams
* Smart pointers
* Lambdas
* Ranges
* Chrono
* Threads
* Error handling
* Utility types
* Other modern C++ features

## Approach

Rather than only reading documentation, I am writing small programs and experiments to better understand how the standard library works and how different features fit together.

The project may include simple examples, exercises, and utility functions as I work through different areas of the language.

## Build

This project uses CMake.

From the project directory:

```bash
cmake -S . -B build
cmake --build build
```

The `build` directory is excluded from source control.

## Notes

This is primarily a learning and refresher project, so the code may change frequently as I revisit concepts, improve implementations, and experiment with different approaches.

The focus is on strengthening my understanding of C++ after spending significant time working in C.
